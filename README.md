# NFC Antenna Generator —— KiCad NFC 天线生成器

> 版本 **1.2.2** · 兼容 **KiCad 8.0 ~ 11**（SWIG Action Plugin）
>
> 已在 **KiCad 8.0.9** 与 **KiCad 10.0.1** 上实测：构建、保存、DRC 均通过。

在 PCB 编辑器里输入参数，**一键生成符合 NFC 布线规范的 13.56 MHz 天线封装**，
并可**一键放置**到当前 PCB。

---

## 功能

| 功能 | 说明 |
|------|------|
| 参数化生成 | 匝数、长宽、线宽、线距、倒角、铜厚、焊盘等全参数可调 |
| 实时预览 | 对话框内实时绘制线圈、丝印、外框、禁铺铜区 |
| 电参数估算 | 电感 L、交/直流电阻、Q、13.56 MHz 谐振电容、导体总长 |
| 布局校验 | 按 NFC 常识检查匝数、电感区间、线宽、线距、长宽比等 |
| 一键放置 | 生成后写入系统剪贴板；回 PCB 按 `Ctrl+V` 粘贴——**封装跟随鼠标**，单击左键放下 |
| 一键入库 | 保存为标准 `.kicad_mod`，写入你指定的 `.pretty` 封装库 |

## 安装

### 方式一：PCM 安装（推荐）

从 Releases 下载 `nfc-antenna-generator.zip`，然后：
KiCad → **插件和内容管理器 (PCM)** → **从文件安装…** → 选择该 zip。

### 方式二：手动安装

把 `plugins/` 目录复制到 KiCad 用户插件目录：

- **Windows**: `%USERPROFILE%\Documents\KiCad\<版本>\scripts\plugins\`
- **macOS**: `~/Documents/KiCad/<版本>/scripts/plugins/`
- **Linux**: `~/.local/share/kicad/<版本>/scripts/plugins/`

安装后重启 KiCad，或 **工具 → 外部插件 → 刷新插件**。

### 方式三：本仓库直接打包

```bash
python package.py            # 生成 nfc-antenna-generator.zip
python package.py --install  # 同时复制到 PCM 缓存目录
```

## 使用方法

1. 打开 PCB 工程，点击工具栏 **「生成 NFC 天线」**。
2. 在左侧填参数，右侧实时预览与估算会自动刷新。
3. 选择动作：
   - **生成封装** —— 写入下方指定的 `.pretty` 封装库；
   - **生成并复制（去粘贴）** —— 把封装写进系统剪贴板，窗口自动关闭；
     回到 PCB 编辑器按 **`Ctrl+V`**，封装就会**跟着鼠标走**，单击左键放下。

> 为什么用「复制 + 粘贴」而不是插件直接放？
> KiCad 8/10 的 Python API 既没有光标位置接口，也无法唤起原生移动工具。
> 而按 `kicad_clipboard.cpp`，KiCad 的 PCB 剪贴板格式就是**纯文本
> `wxTextDataObject`**，内容是裸的 `(footprint ...)` s-expression。
> 因此把封装的 s-expression 写进剪贴板，KiCad 的粘贴就会自然接管，
> 完全跟随鼠标——这也是最稳的做法。

## 参数

| 参数 | 默认 | 说明 |
|------|------|------|
| 匝数 N | 4 | NFC/HF 天线常见 3~6 匝 |
| 天线长 / 宽 | 45×45 mm | 铜箔外框尺寸 |
| 线宽 | 0.6 mm | 常见 0.3~1.5 mm，越宽 Q 越高 |
| 线间距 | 0.5 mm | 常见 0.3~1.0 mm，工艺下限 ≈ 0.15~0.2 mm |
| 转角 45° 倒角 | 0 | 倒角可降低转角处的电流拥挤与损耗 |
| 出线边 | 宽边 | 接线焊盘落在**长边（上/下边）**还是**宽边（左/右边）** |
| 出线位置 | 下端 | **上端 / 中点 / 下端**；选「中点」就从那条边的正中间开始绕 |
| 端子方式 | 内侧端子 | 见下方「两种拓扑」 |
| 过孔外径 | 0.6 mm | 仅「外侧双焊盘」模式使用（≤ 线宽才能保持线距） |
| 过孔钻径 | 0.3 mm | 仅「外侧双焊盘」模式使用 |
| 焊盘钻径 | 0（SMD） | >0 则接线焊盘改为通孔 |
| 铜厚 | 35 µm | 1 oz = 35 µm；越厚 Q 越高 |
| 丝印边距 | 1.0 mm | <0 则不画丝印外框 |
| 禁铺铜外扩 | 2.0 mm | 输出 `Dwgs.User` 禁铺铜提示框 |

## 出线（接线焊盘）位置

`出线边` × `出线位置` = **6 种位置**，配合在 PCB 里旋转封装，就能把接线端子朝到任意方向：

| 出线边 | 上端 | 中点 | 下端 |
|--------|------|------|------|
| **长边**（上/下边，长 L） | 左下角 | 底边正中 | 右下角 |
| **宽边**（左/右边，长 W） | 左上角 | 左边正中 | 左下角 |

> 示例：默认「宽边 · 下端」= 左下角（与旧版行为一致）。
>
> **关于「中点」**：单层平面螺旋只有一个导体，从边的中间开始绕时，
> 换层的接缝必须落在起点的角向位置，否则绕向会反向、磁场相互抵消。
> 本插件用「沿同心矩形顺时针绕行、每层走 
> 周长 − 一个 pitch 后向内跨一个 pitch」的算法实现，
> 因此无论起点在哪里，绕向始终一致、不会自交，
> 且最外圈只留一个 pitch 的接缝（已数值校验）。
>
> 换层接缝用 **垂直向内跨一个 pitch** 实现。
>
> 为什么不做成 45° 斜坡？因为两层斜线之间的垂直距离是 `pitch/√2`，
> 会把线距压到实际的 0.707 倍（实测 0.6/0.5 参数下只剩 0.178 mm），
> 违反「线距处处相等」的 NFC 线圈规范。垂直跨接时相邻两层平行段间距
> 恒等于 `pitch`，净距严格等于设定的**线间距**（已数值校验）。

## 两种拓扑

平面螺旋天然「一端在内、一端在外」，所以提供两种端子方式：

### 1. 内侧端子（默认，单层）

- `pad1` 在**外**端子，`pad2` 在**内**端子。
- 无跨线、无短路风险，**DRC 全洁**。
- 适合 **NFC 标签**：把芯片放进线圈内直接连接（符合 ST AN2972 §3.4.1
  「芯片应尽量靠近天线」），或用过孔把内侧端子引到背面再接匹配网络。

### 2. 外侧双焊盘（B.Cu 过孔跨接）

- 内侧端子经**一个过孔 → B.Cu 回线 → 另一个过孔**引到外侧，两个接线焊盘都
  落在天线外，方便接匹配网络。
- 适合 **NFC 阅读器**。
- 过孔默认 **Ø0.6 / 孔 Ø0.3**（外径 = 线宽，此时与相邻匝的净距仍等于线距）。
- B.Cu 回线在 F.Cu 线圈下方穿过（不同层，不短路），会略微增加寄生电容，
  实际调谐时请注意。

## 线距保证（v1.2.2）

插件保证**匝与匝之间、以及焊盘/过孔到相邻匝之间**的铜箔净距处处相等，
都等于设定的「线间距」。做法：

1. **匝间**：同心矩形螺旋每层向内跨一个 pitch（= 线宽 + 线距），
   相邻两层平行段的净距恒为线距。
2. **焊盘**：用**椭圆长条**焊盘，局部坐标轴沿端子走线方向——
   - 沿走线方向收窄到 `min(焊盘尺寸, 线宽)`；
   - 沿法线方向加长到 `max(焊盘尺寸, 线宽)`，并沿法线外移
     `(长边 − 线宽)/2`，使近边恰好落在端子铜箔远边。

   于是焊盘与相邻那一匝的净距恰好 = 线距，同时靠自由侧伸长保证可焊接面积。
   焊盘角度按端子实际走线方向旋转（旋转封装后仍成立）。
3. **过孔**：外径 = 线宽时中心正好落在走线端点，到相邻匝净距 = 线距；
   外径大于线宽会压缩间距（GUI 会提示）。

校验方式：`kicad-cli pcb drc` 在 KiCad 8.0.9 / 10.0.1 下对
**16 种配置全部 0 违例、0 未连接、0 封装错误**；另有纯几何脚本
（`_dev/check_clearance.py`、`_dev/check_pads.py`）从**已保存的封装文件**里
读回焊盘再算一遍净距，实测最小净距 = 设定线距（0.500 mm / 0.300 mm）。

> 注意：DRC 无法发现匝间净距问题（整圈线圈是同一个实心多边形 + 同一网络），
> 所以这一步靠上面的几何计算保证。

## 设计依据（NFC 布线规范）

本插件不是简单复刻某个开源脚本，而是按下列规范实现：

**ST AN2972《How to design an antenna for your ST25R NFC reader》**

- **§3.2 电感公式**（Modified Wheeler），用于本插件的电感估算：
  $$L = K_1\,\mu_0\,N^2\,\frac{d}{1 + K_2\,p},\qquad
    d = \frac{d_{out}+d_{in}}{2},\quad
    p = \frac{d_{out}-d_{in}}{d_{out}+d_{in}}$$
  方形取 $K_1 = 2.34$、$K_2 = 2.75$。
- **§3.4.1** 芯片应尽量靠近天线（数 mm 内）→ 本插件默认把两个端子放在同一侧。
- **§3.4.2** 天线正上、正下与四周**都不允许有铜（地平面）**，也不允许有短路环
  → 插件输出 `Dwgs.User` 的**禁铺铜提示框**，请在 PCB 上把该区域内的铜皮挖空。
- 天线下方**不要铺地**；天线区域建议单独留出，不与地平面重叠。

**KiCad 官方库 `RF_Antenna.pretty`**（如 `Texas_SWRA117D_2.4GHz_Left`）

- 天线铜箔是 **F.Cu 实心多边形**（`fp_poly` + `fill solid`），而不是一堆折线；
- 两端焊盘用 **`net_tie_pad_groups "1,2"`** 声明为同一导体——**天线本身就是一个
  「净绑器件」**（像 0 Ω 电阻一样跨接两个网络），因此不会产生
  「Pad near pad / 短路」类 DRC 误报；
- 封装属性设为 `exclude_from_pos_files` + `exclude_from_bom`（天线不参与贴片/BOM）。

> 这也是本插件与常见「天线生成脚本」最大的区别：那些脚本把线圈塞进两个自定义
> 焊盘、再把内侧端子用一条同层引线绕出来，必然与其它匝重叠，导致短路。
> 本插件用「实心铜多边形 + 净绑」表达，**16 种配置在 KiCad 8.0.9 与 10.0.1 的
> `kicad-cli pcb drc` 下均为 0 违例、0 未连接**。

## 已知限制

- **电感/Q 为估算**：Q 是理想上限，未含介质损耗与匝间邻近效应，实测通常更低。
  请用阻抗分析仪 / 网络分析仪实测，或使用 ST eDesignSuite、NXP 天线工具校核。
- **封装内不能放过孔**：KiCad 8 的 `.kicad_mod` 不支持 `via`（已实测），
  「外侧双焊盘」模式用通孔焊盘充当过孔。
- **不生成地平面挖空**：封装无法定义 keep-out zone，请按 `Dwgs.User` 提示框
  手动在天线区域禁止铺铜。
- 天线是「净绑器件」，与原理图无对应符号；`exclude_from_bom` 已屏蔽 BOM 影响，
  如需 ERC/DRC 中不提示，可在工程里加 DRC 排除项。
